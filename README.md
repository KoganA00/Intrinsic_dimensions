# Intrinsic_dimensions
Repository for paper "Semantic spaces of the natural languages and their intrinsic dimensions: comparative analysis" Vasilii A. Gromov, Inna V. Skrynnikova, Alexandra S. Kogan,  and Artem I. Serikov

Code for intrinsic dimension computation is taken from [whiteroomlz/intrinsic-dimensions-computation](https://github.com/whiteroomlz/intrinsic-dimensions-computation)

Code for entropy-complexity computation is taken from [quynhu-d/semantic_sentiment_trajectories](https://github.com/quynhu-d/semantic_sentiment_trajectories)
